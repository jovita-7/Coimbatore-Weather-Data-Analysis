# Coimbatore Weather Data Analysis

## Project Overview
This is a beginner-level Data Analytics project that explores weather data for Coimbatore over a sample period of 7 days.

## Objectives
- Analyze daily temperature
- Study humidity levels
- Examine rainfall patterns
- Understand weather conditions

## Tools Used
- Google Sheets
- GitHub

## Dataset Description
The dataset contains Date, Temperature, Humidity, Rainfall, Wind Speed, and Weather Condition.

## Analysis Performed
- Average temperature calculation
- Maximum and minimum temperature analysis
- Average humidity calculation
- Total and maximum rainfall calculation
- Temperature and rainfall charts

## Key Findings
- Maximum temperature: 31°C
- Minimum temperature: 27°C
- Average temperature: 28.86°C
- Average humidity: 76.43%
- Total rainfall: 19 mm

## Conclusion
This project demonstrates basic data organization, analysis, and visualization using Google Sheets.

Note: The dataset contains sample values for learning and practice, not verified historical weather records.
